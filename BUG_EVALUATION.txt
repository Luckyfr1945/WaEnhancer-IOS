[BUG-PRV-01] Freeze Last Seen Tidak Berfungsi Jika Diaktifkan dari Pengaturan Aplikasi
- File Target    : app/src/main/java/com/wmods/wppenhacer/xposed/features/privacy/FreezeLastSeen.kt
- Baris Kode     : 18 - 33
- Status         : [SUDAH DIPERBAIKI / FIXED]
- Gejala         : User mengaktifkan "Bekukan Terakhir Dilihat" di aplikasi WaEnhancer, namun waktu
                   terakhir dilihat tetap terupdate dan tidak beku di WhatsApp.
- Akar Masalah   :
  Terdapat logika ganda:
    val freezeLastSeenMain = prefs.getBoolean("freezelastseen", false)
    val showFreezeOption = prefs.getBoolean("show_freezeLastSeen", true)
    val freezeLastSeenPriv = getPrivBoolean("freezelastseen", false)
    val isFrozen = if (showFreezeOption) {
        freezeLastSeenMain && freezeLastSeenPriv
    } else {
        freezeLastSeenMain
    } || ghostmode
  `showFreezeOption` bernilai default `true`. Namun `freezeLastSeenPriv` tersimpan di database internal
  WhatsApp (getPrivBoolean) yang awalnya bernilai `false`. Karena evaluasinya `main && priv`,
  maka `true && false = false`. Fitur tidak akan aktif sampai user menemukan toggle tersembunyi
  di dalam menu WhatsApp.
- Severity       : TINGGI (Fitur utama privasi tidak bekerja bagi mayoritas pengguna).
- Solusi Diterapkan:
  Memperbaiki logika evaluasi: `val isFrozen = freezeLastSeenMain || (showFreezeOption && freezeLastSeenPriv) || ghostmode`.
  Mengaktifkan toggle di pengaturan WaEnhancer kini langsung membekukan waktu terakhir dilihat secara instan.

[BUG-GEN-01] Refleksi Liar & Eksekusi Method Berbahaya pada Anti-Revoke Pesan Masuk
- File Target    : app/src/main/java/com/wmods/wppenhacer/xposed/features/general/AntiRevoke.kt

    for (m in cls.methods + cls.declaredMethods) {

[BUG-MED-04] CallRecording: Memerlukan Root `su` yang Pasti Gagal di Lingkungan Normal WhatsApp

- Status         : [SUDAH DIPERBAIKI / FIXED]
- Gejala         : Menekan tombol Transkripsi Suara membuat WhatsApp macet total (freeze) dan memicu
                   dialog Android "WhatsApp tidak menanggapi" (ANR).
- Akar Masalah   :

- Solusi Diterapkan:
